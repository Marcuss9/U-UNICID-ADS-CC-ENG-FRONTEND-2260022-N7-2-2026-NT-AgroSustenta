CENÁRIO PAGO · CONTRATO INICIAL

Hostinger Single: hospedagem, servidor e domínio

Hospedagem + servidor: o plano Single utiliza os servidores compartilhados da Hostinger para publicar o site; não é preciso pagar por outro servidor. Preço promocional: R$ 5,99/mês é a média de um compromisso de 48 meses, com total de R$ 287,52 antecipado (ou parcelado conforme as condições de pagamento).

Domínio .com.br: é o endereço personalizado, diferente da hospedagem. A Hostinger anuncia domínio grátis no Single, mas isso não garante automaticamente um .com.br nem gratuidade em todas as renovações. Se não estiver elegível, o domínio pode ser registrado separadamente, por exemplo no Registro.br.

R$ 327,88/12 meses equivalentes*

Exemplo de renovação com domínio pago: hospedagem R$ 23,99 × 12 = R$ 287,88 + domínio .com.br R$ 40 = R$ 327,88. Sem cobrança adicional pelo domínio, o exemplo cai para R$ 287,88.

*Esta é uma comparação didática de 12 meses, não necessariamente uma fatura anual. O plano anunciado usa ciclo de 48 meses e a renovação pode ter a mesma duração. Consulte o total exigido no checkout, os impostos, a disponibilidade do domínio e as condições de renovação. Valores de referência consultados em 16/11/2026.

QUAL É A MELHOR ESCOLHA?

Contratar só o que o projeto precisa.

Recomendação para o AgroSustenta

O AgroSustenta é um site estático, feito com HTML, CSS e JavaScript. Ele não utiliza banco de dados nem precisa executar código no servidor para entregar as páginas. Por isso, o GitHub Pages atende ao projeto sem custo de hospedagem.

Se a equipe quiser um endereço próprio, pode adicionar um domínio .com.br por R$ 40 ao ano, mantendo a hospedagem gratuita. Não é necessário contratar um servidor separado para a versão atual do site.

Quando contratar um servidor pago?

Uma hospedagem paga pode fazer sentido se o projeto passar a precisar de backend, processamento no servidor, banco de dados gerenciado, e-mail profissional ou suporte comercial. Nesse cenário, compare o preço de renovação, o período mínimo contratado e os recursos incluídos.

Na opção Hostinger, o servidor compartilhado e o espaço de hospedagem fazem parte do plano Single. Não some um segundo servidor ao orçamento sem uma necessidade técnica.
