PUBLICAÇÃO

Preparado para
o Railway.

  1. Conecte o repositórioNo Railway, crie um projeto a partir do GitHub e selecione a branch desejada. Use a raiz do repositório.
  2. Deixe o Dockerfile trabalharO Nginx serve apenas a pasta src. Não há instalação de pacotes nem build do front-end. O servidor escuta na variável PORT.
  3. Gere um domínioAtive o domínio público do serviço e verifique as dez páginas. O healthcheck usa /index.html.

O GitHub Pages continua disponível como alternativa: o workflow manual publica a pasta src, sujeito à elegibilidade do repositório.

SUSTENTABILIDADE DIGITAL

Menos transferência.
Mais conteúdo.

Fontes do sistema, imagens locais em WebP, mídia sem autoplay e nenhum framework reduzem dependências e transferências desnecessárias.

Não atribuímos neutralidade de carbono a provedores sem evidência específica. Uma comparação ambiental entre hospedagens exigiria dados de energia, região e uso real.
