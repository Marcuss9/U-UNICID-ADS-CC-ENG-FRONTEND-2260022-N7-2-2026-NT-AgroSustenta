# 02 — Arquitetura e organização

**Obrigatório**
- Preserve a solução estática: HTML em `src/`, CSS em `src/css/`, JavaScript em `src/js/`, recursos em `src/assets/` e documentação em `docs/`.
- Não introduza backend, banco, framework, bundler, dependências, `package.json` ou build por conveniência. Exceções requerem autorização específica e justificativa.
- Preserve caminhos relativos locais para navegação, imagens, iframe, vídeo e legendas: o site deve funcionar tanto em raiz HTTP quanto no prefixo de repositório do GitHub Pages.
- Preserve `src/assets/quadro.html` como iframe local, não como página principal.
- Não mova, renomeie ou apague arquivos sem necessidade aprovada; nunca altere dados ou evidências originais somente para adequar organização.
- Evite duplicar código ou mudar estrutura por estética; prefira alterações mínimas e legíveis.

**Verificação:** reveja caminhos de todos os arquivos tocados, links internos e ausência de dependências novas.
